# 약속 우체국 · DB-PROMY

Issue #1, AGENTS.md와 사용자의 후속 돌탑·별자리·굿즈 요구를 반영한 3D 체험 데모입니다. **약속 실천 → 하루 한 개의 돌 → 100개 돌탑 완성 → 프로미 선물 뽑기**가 코어입니다. 세 돌탑(300개)으로 나의 연간 약속을 완성합니다.

## 실행

Node.js 22 이상에서 `npm ci`, `npm run serve`를 실행하고 [로컬 동네](http://127.0.0.1:4173/world.html)를 엽니다. GLB와 모듈 로딩을 위해 HTTP 서버를 사용하세요. 상대 경로를 사용하므로 GitHub Pages 하위 경로에서도 작동합니다.

| 주소 | 용도 |
|---|---|
| world.html | KST 실시간 3D 동네 |
| world.html?admin=1 | 시각·시뮬 이웃·21시·100일·카드·영상 시연 |
| world.html?demo=1 | 실제 기록과 분리된 돌탑 시연. 키보드 1키로 돌 추가 |
| world.html?spectate=1 | 관람 카메라, 참여 버튼 비활성 |
| world.html?quality=low | 저사양 모드 |
| fallback.html | 같은 localStorage를 쓰는 2D Canvas 동네 |
| backup.html | 실제 브라우저에서 녹화한 20초 MP4 백업 |
| widget.html | 로컬 등불·시뮬레이션 이웃 위젯 |
| index.html / world-2d.html | 기존 제안서 / 이전 프로토타입 |

`?src=reels|story|blog|qr-camp|qr-concert|kakao`는 로컬 유입 카운터입니다. `?name=`은 정해진 캠프 네임 6개만 허용합니다. 자유 입력·약속 원문·연락처는 받지 않습니다.

약속 여섯 가지(식사·하루 마치기·안전한 도착·물 한 잔·잠깐 쉬기·출발 전 확인) 중 하나를 선택하고 실천을 확인하면 내 돌을 직접 올릴 수 있습니다. 실제 모드는 KST 하루 한 개이며, 돌탑과 나의 별 찾기는 독립적으로 진행됩니다. 100/200/300개마다 돌탑 완성과 뽑기 기회, 생활 약속별 최초 100회에도 별도 뽑기 기회가 생깁니다. 같은 날짜의 동일 약속은 중복 계산하지 않습니다.

시연 모드에서는 `1`키 또는 돌 추가 버튼으로 300개까지 연속 쌓을 수 있습니다. 시연 기록·당첨 보관함은 실제 기록과 분리해 저장하고, 시연 초기화도 실제 기록을 지우지 않습니다. 저장 스키마 v4가 기존 v1/v2/v3 기록을 보존해 이전합니다. 이전 기록을 소급해서 돌이나 실물 보상 자격으로 만들지 않습니다.

사용자가 화면 사용을 요청한 HTML의 프로미 굿즈 디자인 20종만 개별 이미지로 추출했습니다. 원본 HTML·브리프·캐릭터 참고 이미지는 공개하지 않습니다. 뽑기는 현재 로컬 시연이며, 지급·재고·배송 운영이 연결되지 않았습니다. 따라서 배송 접수 버튼은 준비 중으로 표시하고 개인정보를 받지 않습니다. 당첨 기록도 배송 완료로 표시하지 않습니다.

Instagram 버튼은 스토리/피드 규격 PNG 한 장을 기기 공유창으로 전달합니다. 사용자가 Instagram을 선택하고 게시를 마칩니다. 웹에서 Instagram을 강제 선택하거나 게시 성공을 확인하지 않습니다. 직접 전달을 지원하지 않는 기기는 PNG 저장·문구 복사·Instagram 열기로 이어집니다. `node scripts/improvements-qa.js`가 이미지 크기, 한 장 전달, 취소/미지원, 기록 복원, 모바일/2D 루프를 검증합니다. 실제 Instagram 앱 게시 확인은 실기 테스트가 필요합니다.

PC는 크림색 몸·주황 컬, NPC는 노란 비대칭 머리·초록 스카프/망토의 별도 GLB입니다. 제작 소스는 scripts/build-assets.js, 압축 후 크기·삼각형·클립 목록은 assets/glb/manifest.json에 있습니다. 원본 브리프·캐릭터 이미지·NPC HTML은 공개 저장소에 포함하지 않았습니다.

## 검증과 재생성

`npm test`로 상태/에셋 테스트 27개를 실행합니다. 다른 터미널에서 서버를 실행한 뒤 `npm run qa`로 별자리·하늘·돌탑·저전력 브라우저 QA를 실행합니다. 기존 돌탑 루프 검증은 `npm run qa:towers`입니다. 실제 1키 입력 300회, 100→101 전환, 뽑기·굿즈 이미지·복원·실제/시연 분리·별자리·공유 PNG·모바일·2D를 확인합니다. QA 브라우저가 없으면 `npx playwright install chromium`을 실행하세요. PLAYWRIGHT_BROWSERS_PATH를 지정한다면 설치와 실행에 같은 경로를 사용합니다. 이전 스프린트 QA 스크립트는 당시 UI용으로 보존되어 있습니다.

모델·벤더·카피를 변경한 뒤 `npm run vendor`, `npm run assets`, `npm run offline`으로 생성물을 갱신합니다. 첫 온라인 방문에서 코어 오프라인 캐시를 준비합니다. MP4는 초기 다운로드에 포함하지 않으므로 발표 전에 백업 파일을 별도로 준비하세요.

상세 구현 범위·측정 결과·남은 실기/아트 검증은 [수용 기준 기록](./docs/ACCEPTANCE.md)에 정리했습니다. 격리된 브라우저 6개 검증은 실물 휴대폰 검증이나 실시간 동기화를 의미하지 않습니다.

**DEMO · 실제 DB손해보험 서비스가 아닙니다.** 이웃 수는 시뮬레이션이며 기록은 브라우저별입니다. 운영자 파라미터는 보안 인증 기능이 아닙니다. 상용 운영 전 브랜드·캐릭터 권리와 법무·준법·개인정보 검토가 필요합니다.

## 생일 별자리와 재방문 카드

나의 별 찾기에서 생일 월·일을 선택하고 방문을 쌓으면 생일 기준 12궁 별자리를 점차 그립니다. 0회에는 별자리가 없고 100회에 완성됩니다. 연도는 받지 않고 월·일은 브라우저에만 저장합니다. 돌탑이나 선물 뽑기와 독립적이며 별 찾기는 뽑기권을 지급하지 않습니다.

실제 방문은 새 탭 세션별 한 번이며 같은 탭의 새로고침·2D 전환은 중복 계산하지 않습니다. 100회부터 기념 카드가 열립니다. 100번째 방문 날짜를 기준으로 올해 남은 일수를 계산하고 200/300회마다 문구와 날짜를 갱신합니다. 9월 10일의 당일 제외 연말 잔여일은 112일입니다. 시연 `?demo=1`에서는 **2키** 또는 방문 +1 버튼을 사용합니다. **1키는 돌 쌓기**입니다. 두 카운터와 실제/시연 기록은 독립적입니다.

기본 메시지는 AI 연동 전 로컬 조합형 시연 문구로 명시합니다. 실제 생성형 서버는 `brand.starMessageEndpoint`의 동일 출처 POST API로 연결할 수 있으며 생일 월·일은 전송하지 않습니다. 생일 기준 도식은 정밀 천문 관측 지도나 운세가 아닙니다. 12궁 날짜 기준: https://production.royalmint.com/gifts/zodiac/a-guide-to-the-zodiac/ .

선물·별자리 모달은 이동/카메라를 멈추고 닫으면 기존 상태를 유지합니다. 세션 내 재접속 시 위치·시점·사이드바 스크롤을 복원합니다. 돌탑 레이블은 모달 뒤로 숨깁니다. 사용자가 제공한 「지금 그대로」 MP3를 사운드 버튼으로 재생/일시정지하며 반복 재생합니다. 최초 재생은 버튼 클릭으로 시작합니다.

`node scripts/birthday-qa.js`는 별자리 입력, 99/100/200회, 별찾기 무보상, 모달 레이어, 당첨·방문 기록 복원을 검증합니다.


시연 초기화: **0키 = 돌탑·시연 뽑기 기록 초기화**, **9키 = 별 찾기 시연 방문 횟수·100회 카드 초기화**. 두 기능은 서로의 진행과 생일 월·일, 실제 기록을 유지합니다. 상단 숫자키와 숫자 패드 모두 지원하며 길게 누른 반복 초기화는 막습니다. 입력/선택창을 편집할 때는 실행하지 않습니다. 모바일에는 같은 이름의 초기화 버튼이 있습니다. 저장된 돌탑이 재접속 때 보이는 것은 기록 유지 동작입니다.

음원 `assets/audio/jigeum-geudaero.mp3`는 사용자가 제공한 약55초 MP3입니다. 기본 음량40%, 반복 재생. 선물·별자리 모달을 열어도 음악은 유지됩니다. `node scripts/reset-music-qa.js`로 0/9키 독립 초기화·새로고침0 유지·실제 음원 디코딩/재생·끝에서 처음으로 반복·일시정지/재개·2D를 검증합니다.


## 최신 동작: 별의 성장과 하늘

별자리는 방문0회에는 비어 있고, 1~99회는 일부 선만 이어지며 100회에 완성됩니다. 100/200/300회 메시지 카드는 유지하고 방문365회 다음의 366번째 방문에서는 카운터·카드를0으로 초기화합니다. 생일과 돌탑은 보존합니다. 화면에 시연 초기화·단축키 안내·모드 전환 버튼은 표시하지 않습니다. 0/9/1/2키는 시연 URL에서 숨은 조작으로 유지합니다.

하늘 보기에서 내 별과 이웃 별자리 도식을 함께 봅니다. 실제 다중 사용자 서버가 없으므로 이웃은 시뮬레이션으로 표시합니다. 시연8키는 1월1일부터 하루씩 다른 생일의 별자리를 추가하고 12월31일의365개에서 멈춥니다. 7키는 이웃 별자리만 비웁니다. 2월29일 개인 생일은 지원하지만 이웃 순서는 평년365일입니다. 별자리는12종이므로 같은12궁 생일은 같은 도식을 공유합니다. 동네로 돌아가면 이전 시점을 복원합니다. 2D에도 하늘 뷰를 제공합니다.

100돌 완성 돌탑은 높이약2.142로 축소해 플레이어 키약2.15에 맞춥니다. 위에 약속 문구와 실제NPC GLB를 미리 렌더한 작은 프로미 PNG를 표시합니다.

기본 저전력: 픽셀비율최대1(넓은 화면은1600px 기준), 그림자/블룸끔, 동적조명4개, 배경별1500개 버퍼, 이동/연출최대30fps·대기15fps·모달2fps·숨은탭중지. 상태 계산/별자리 버퍼는 변경 때만 갱신하고 레이블은10Hz로 제한합니다. `?quality=high`만 고화질 효과를 선택합니다. 팬 소음·소비전력은 실기 측정 전이며 브라우저 렌더 부하를 줄인 결과입니다.


### 수정: 일반 주소의 8/7키와 360도 하늘

8/7키는 이제 `demo=1` 없이 일반 `world.html`에서도 작동합니다(관람/입력 편집 중 제외). 8키를 누르면 하늘 보기로 즉시 전환하고 1월1일,1월2일 순으로 새 생일을 추가하며 해당 별자리 방향을 바라봅니다. 날짜·누적 수를 표시합니다. 7키는 이웃을 비우고 다음8키는 다시1월1일입니다. 이웃은 여전히 시뮬레이션입니다.

이전 평면 배치를 폐기하고 반지름70의 하늘 반구에 방위각360도로 배치했습니다. 드래그로 시점을 회전할 수 있고 일반 하늘 보기 버튼은 내 별 방향으로 갑니다. 별/선은 동일한 배치 버퍼를 사용해 드로콜을 늘리지 않았습니다. 2D는 파노라마 대신 평면 하늘 도식을 제공합니다.

구버전 코드 잔류를 줄이기 위해 서비스워커의 HTML/JS/CSS/JSON은 네트워크 우선·실패 시 오프라인 캐시로 변경하고, 기존 제어기가 새 버전으로 바뀌면 페이지를 한 번 갱신합니다. `node scripts/sky-keyboard-360-qa.js`가 일반 주소와 실제 키 입력,1/1→1/2,자동 시점,드래그,7초기화,2D를 검증합니다.


### 숫자 단축키 통합 수정

일반 `world.html`에서도 0/1/2/7/8/9 및 숫자패드가 작동합니다. 1은 돌 추가,2는 방문 추가,0은 돌탑/시연당첨 초기화,9는 방문/카드 초기화,8은 생일별 하늘 추가,7은 이웃 하늘 초기화입니다. 0/1/2/9 첫 입력 시 이동이나 새로고침 없이 분리된 테스트 기록으로 전환하고 세션 내 재접속에도 유지합니다. 실제 기록은 보존합니다. 버튼 UI에 기술 안내는 표시하지 않습니다.

1/2키는 모달이 열려 있으면 닫고 처리하며2는 별 찾기 창을 유지합니다. 생일 선택/텍스트 입력 중이나 관람 모드에서는 실행하지 않습니다. 300돌이 이미 완성된 상태의1키는 완료 문구를 표시합니다. `npm run qa:keys`가 일반 주소의 모든 숫자/숫자패드,모달·하늘왕복,세션저장,실제기록보존,입력/관람가드,2D를 검증합니다.
