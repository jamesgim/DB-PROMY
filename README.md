## 전략 구조
**보여주는 세계(World) × 돌아가는 AI 엔진(Engine) × 지속하는 운영(Operations)**

1. 슬로건: **그대로의 나를 위한, 함께 약속** (브랜드 승인 전 제안안)
2. 공간: **약속 우체국** (가칭, 상시 열려 있는 브랜드 공간)
3. 허브: **프로미 우체통 2.0**
4. 참여: 약속 걸기 → 등불 켜기 → 실천 확인 → 별 남기기
5. 확장: 익명화된 참여 신호와 승인형 AI 콘텐츠 제작 파이프라인

## 검증 및 유의사항
- 업로드된 DB손해보험 RFP/브랜드 자료 원본을 아직 확인하지 못했습니다. **사용자 제공 전략을 바탕으로 한 v0.1 컨셉 시안**입니다.
- 경쟁사 비교, 심사위원 구성, 우체통 누적 실적, 15년 보험 운영 경력 등은 별도 근거 확인 후 확정하세요.
- '상품 언급 0 = 심의 비대상'은 보장할 수 없습니다. 관련 광고심의·법무·개인정보·보안 검토가 선행되어야 합니다.
- '매일 완전 무인 숏폼 게시'보다 **자동 생성 + 사람 검수·승인** 모델을 기본으로 권장합니다.
- 웹 접근·익명 참여·원문 비저장, 2개월 MVP 등은 기술/예산/보안 범위를 확인해 확정해야 합니다.
- 기존 브랜드 로고·캐릭터·브랜드 가이드 이미지가 준비되면 라이선스와 최신 규격 확인 후 교체하세요.

> 이 저장소는 현재 공개(public) 상태입니다. 내부 통화 분석, 경쟁사 전략, 비공개 제안요청서 원문 및 내부 자료를 업로드하지 마세요.


## 동작하는 체험형 MVP (2026-11-04)
`world.html`은 외부 라이브러리·서버가 없어도 브라우저에서 직접 작동하는 인터랙티브 SVG 월드 프로토타입입니다.

- 우체통 → 카테고리 선택 → 등불 생성
- 그대로 확인 → 완수 시 등불 감소·카운터 증가·하늘에 별 생성
- 안부 보내기·불 돋우기, 4개 생활 공간 클릭
- 낮·21시 밤 모드 전환, 시연용 프로미 승인형 대화 플로우
- 초기화와 모바일 UI, 키보드 접근 조작

**현재 구현하지 않은 기능:** 여러 이용자 사이의 실시간 동기화, 실제 DB 통합 카운터 API, 카카오톡/AI 모델 연동, 3D WebGL 자유 이동, 로그인·회신 저장, 자동 숏폼 생성·게시, 실제 정원·대기·QR 동기화. 이들은 다음 개발 단계의 백엔드/API·검증 과제입니다. 시연 숫자는 **브라우저 메모리 내 시연 데이터**이며 실제 통계가 아닙니다.

업로드된 전략 문서 `PART2_슬로건_그대로의나_새해캠페인.md`, `PART4_장치1_기억하는프로미.md`, `PART4_장치5_약속우체국_월드.md`에 있는 제안 컨셉을 바탕으로 제작했습니다. 비공개 내부 문서 자체는 Public 저장소에 포함하지 않았습니다.

**주의:** 프로미 공식 캐릭터 모델은 브랜드 자산 확인 전까지 대체 일러스트를 사용합니다. 제안 문서의 심의 비대상·개인정보·경품 관련 법적 단정은 적용하지 않으며, 법무·준법·개인정보 담당 검토가 필요합니다.


## 3D World v0.3 (Three.js)
- `world.html`을 Three.js/WebGL 실시간 3D 세계로 교체했습니다.
- 카메라 드래그 회전·휠 줌, WASD/방향키 이동, 모바일 가상 조이스틱, E 상호작용, 우체통·공원·운동장·횡단보도·저녁 식탁.
- 3D 인물과 **시뮬레이션 NPC** 16명, 나무·벤치·가로등·건물·모닥불·우체통·별 및 시간대 조명 연출.
- 새해 약속 카테고리 선택 → 등불 생성 → 지킴 확인 → 별 카운터 변화. 프로미 대화는 사전 구성된 시나리오 목업입니다.
- 공식 프로미 3D 모델·브랜드 자산은 포함하지 않습니다. 현재는 대체 로우폴리 캐릭터입니다.
- **완성도 경계:** 산사 월드와 같은 사진 기반 고급 텍스처·스캔 에셋·동시 접속·물리엔진·서버 렌더/동기화를 구현한 버전은 아닙니다. 실제 상업 서비스로 운영하려면 품질 높은 GLB/텍스처, 최적화, 서버, 접근성, 개인정보·보안 검토가 필요합니다.
- Three.js 0.160.1 CDN을 불러오므로 최초 실행에는 네트워크가 필요하며, WebGL 지원 브라우저에서 실행해야 합니다.
